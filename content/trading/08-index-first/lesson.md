# 看盘的顺序：先看天再看地

## 一、一个常见的亏钱开场

很多散户的看盘习惯是这样的：开盘打开软件，直接切到自选股页面，
眼睛死死盯住手里那几只票的分时线，心跳跟着红绿跳动。到收盘一看，
自选股跌了两个点，心里纳闷：「今天大盘不是涨的吗？我的票怎么还跌？」

问题就出在**顺序**上。你先看的是「自己那两亩地」，却没抬头看「天」。

老手看盘的顺序一般是反过来的：**先看天（大盘指数），再看地（板块），
最后才落到个股。**「天」是整个市场的环境，「地」是资金扎堆的方向，
个股只是天地之间的一棵苗——天要下雨，苗再壮也躲不过；风向不对，
你那片地再肥也白搭。

（先说明：这是市场参与者的**经验性总结**，不是定律。但它背后的逻辑很硬，
下面一层层讲清楚。）

## 二、先看天：大盘告诉你今天顺风还是逆风

A 股几千只股票，绝大多数的涨跌方向，是被「大盘」带着走的。大盘涨的日子，
大多数股票容易涨；大盘跌的日子，大多数股票容易跌——这叫**系统性影响**，
跟你选的票好不好关系不大。

所以开盘第一件事不是问「我的票涨没涨」，而是问：
「**今天市场整体是顺风还是逆风？**」顺风天，做错也容易对；逆风天，
做对也容易错。追涨杀跌的散户，很多就亏在逆风天还满仓猛干。

## 三、上证分时图上的黄白线：一个盘面，两种「真相」

打开上证指数的分时图，你会看到两条线，老股民管它们叫「黄白线」：

- **白线**是上证指数本身，按**市值加权**计算：市值越大的公司
  （银行、石油、白酒这类巨头）对指数的影响越大。白线本质上是
  「**大票的走势**」。
- **黄线**是**不加权**的走势：每只股票不管盘子大小，都按同等权重算平均。
  黄线更接近「**大多数股票的体感**」，也就是中小票的处境。

两条线的相对位置藏着重要信息：

- **白线在上、黄线在下**：大票在涨、小票在跌。指数红彤彤，但你手里
  如果是中小票，很可能是绿的。散户管这叫「**赚了指数不赚钱**」。
- **黄线在上、白线在下**：小票活跃、大票歇脚。这种日子即使指数涨幅不大，
  市场里的「赚钱效应」往往不错。
- 两条线**张口越大**，大小票的分化越严重；缠在一起走，说明大小票
  同涨同跌，盘面比较「齐」。

这不是理论推演，是天天在发生的事。用本站的真实行情举个例子：

比前一交易日涨了 **{{calc:chg_pct(sh000001, 2026-07-17, 2026-07-20)|1}}%**，
看起来是个不错的红盘；但同一天，代表中小盘的{{calc:symbol_name(sh000905)}}
却跌了 **{{calc:chg_pct(sh000905, 2026-07-17, 2026-07-20)|1}}%**。
也就是说，那天只看上证指数，你以为市场在涨；实际上多数中小票在挨揍。
这就是典型的「白线强、黄线弱」。

反过来也有。{{calc:trade_date(sh000001, 2018-02-08)}}，{{calc:symbol_name(sh000001)}}
单日跌了 **{{calc:chg_pct(sh000001, 2018-02-07, 2018-02-08)|1}}%**，盘面绿油油；
可{{calc:symbol_name(sh000905)}}当天反而涨了
**{{calc:chg_pct(sh000905, 2018-02-07, 2018-02-08)|1}}%**——指数大跌的日子里，
中小票其实在回血。如果那天只看指数吓得清仓小票，就割在了地板上。

**一句话：白线告诉你「指数怎么样」，黄线告诉你「大家的股票怎么样」。
散户的持仓大多是中小票，黄线才是你的体感温度。**

## 四、再量体温：涨跌家数和涨跌停家数

指数是加权平均，天然会被大票带偏。要看市场真实的温度，有两个更直接的
指标，任何行情软件首页都有：

**1. 上涨家数 vs 下跌家数**——每天统计全市场多少只股票涨、多少只跌：

- 指数涨，上涨家数也远多于下跌家数 → 真的强，大多数人在赚钱；
- 指数涨，但下跌家数反而比上涨家数多 → 少数大票拉起来的「假红盘」，
  多数股票其实在跌；
- 指数跌，但上涨家数不少 → 跌的主要是大票，多数股票问题不大。

**2. 涨停家数 vs 跌停家数**——市场情绪的「极端值」：

- 涨停一大片、跌停寥寥 → 情绪亢奋，短线资金敢出手；
- 跌停几十上百家 → 恐慌在蔓延，这时候谈「抄底」要格外小心；
- 涨停跌停都很少 → 盘面沉闷，多空都没力气。

（本节定性讲「看什么、怎么看」。家数类数据本站行情库没有收录，
所以本章不给具体数字——打开任何一款行情软件，首页就能看到。）

## 五、最后才是地里的苗：板块和个股

看完天、量完体温，第三步才轮到板块和个股。

- **看板块**：今天的钱在往哪个方向流？涨幅榜前列是哪些板块，跌幅榜
  前列又是哪些？个股很难逆着自己的板块独立走强——板块是「地」，
  个股是「苗」，地力不行，苗很难独善其身。所以你手里的票属于哪个板块、
  那个板块今天排在涨幅榜还是跌幅榜，比这只票本身的分时线重要。
- **看个股**：做完上面两步，最后才打开自选股。这时候心态都不一样了——
  不是「它怎么又跌了」，而是「在今天顺风还是逆风、它的板块强还是弱的
  前提下，它的表现算正常还是异常」。

## 六、为什么只盯自选股，会看不见风险

把上面的逻辑串起来，答案就清楚了：

1. **风险先到天边，再到地里，最后才到你的苗。** 大盘跳水、跌停潮起来的
   时候，先跌的是你没盯着的那些票；等你的自选股开始跌，风险已经扩散到
   你眼前了。只盯自选股，等于放弃了所有提前量。
2. **盯自选股会强化「屁股决定脑袋」。** 你已经买了它，眼睛就会不自觉地
   找利好、忽略坏信号——心理学上这叫**确认偏误**。先把视线放在指数和
   板块上，是逼自己先看「环境」再看「仓位」，判断会冷静一些。
3. **看盘的本质，是先决定「今天该不该动手」，再决定「动哪只手」。**
   顺序反了，就成了「因为手里有票，所以天天找理由持有」。

## 七、一个可以照着做的开机流程（经验之谈）

老股民里流传的开机顺序，供你参考（再次强调：这是经验，不是铁律）：

1. 开盘先看指数：涨跌幅、黄白线谁强谁弱；
2. 扫一眼涨跌家数和涨跌停家数，判断市场温度；
3. 看板块涨幅榜、跌幅榜，搞清楚钱在往哪流、从哪撤；
4. 最后才打开自选股，在前三步的背景下审视持仓：该拿、该减还是该走，
   是跟「天」和「地」对着干，还是顺着走。

收盘复盘，顺序一样。坚持一段时间，你会发现自己「看见」的东西比以前
多得多——这就是本章标题说的：**先看天，再看地，最后才是你那两亩苗。**

## 八、本章小结

- 看盘顺序：**指数 → 板块 → 个股**，先判断环境，再处理持仓；
- 上证分时白线 = 市值加权（大票主导），黄线 = 不加权（多数股票的体感）；
  白上黄下 = 赚了指数不赚钱；
- 涨跌家数、涨跌停家数是比指数更真实的市场体温计；
- 只盯自选股 = 放弃风险提前量 + 强化确认偏误，是散户最常见的看盘误区。
