# A股投资互动教学站

一个跑在本地的 A 股自学训练场：**体系化课文 + 闯关刷题 + 真实历史 K 线实战演练 + 指标参数实验场**。
为「看得懂结论、管不住手」的散户设计——不只讲知识，更训练决策。

> 仅供学习，不构成投资建议。

## 亮点功能

### 📚 四大模块 · 36 章 · 360 道闯关题

| 模块 | 内容 |
|---|---|
| 股市概念（10 章） | 交易规则、指数、K线量能、盘口、估值、分红、ETF、板块轮动、新股/ST/退市 |
| 技术指标（9 章） | 均线、MACD、KDJ、RSI、布林、乖离率、量价进阶、指标局限、V5 交易系统完整拆解 |
| 宏观经济学（9 章） | GDP、通胀通缩、货币/财政政策、社融 M2、利率债券、经济周期、政策市、汇率外资 |
| 看盘技巧（8 章） | 复盘方法、分时、集合竞价、止损止盈、仓位管理、交易计划、交易心理、看盘顺序 |

每章 = 课文 + 10 道带解析的闯关题，应用题为主，不是背书。

### 📈 B 型 · K 线实战演练（11 关）

给你一段**真实历史行情**（隐去未来），K 线走到关键位置停住——你决策：买 / 卖 / 观望？
随后揭示真实走势，并给出「超跌反弹 V5」交易系统当时的完整打分明细。
关卡覆盖 2008 熊市、2013 钱荒、2015 股灾、2020 疫情、2024 大反转等经典场景，
全部信号由代码在真实数据上扫描产生，**没有信号的时期宁可做成反面教材也不编造**。

### 🎛 指标实验场

拖滑块调参数，实时看指标怎么变：双均线、MACD / KDJ / RSI / BIAS 副图，
三大指数（上证/沪深300/中证500）自由切换。
亲手验证「参数越灵敏假信号越多，越迟钝入场越晚——没有圣杯参数」。

### 🛡 数字零幻觉机制（本项目的核心设计）

课文和题目中的**每一个行情数字都由脚本从冻结行情数据计算注入**（`{{calc:...}}` 占位符），
不允许任何手写——AI 参与写内容也无法编造数字。`check.sh` 会在临时库副本上逐一试算所有占位符。

### 📒 学习数据

答题记录、错题本（答对自动移出）、关卡最好成绩、亮/暗主题切换。
重建数据库时学习数据**自动备份恢复，永不丢失**。

## 快速开始

环境要求：Python 3.10+（Linux / macOS / WSL）。

```bash
./start.sh      # 一键起站并打开浏览器（自动建环境、装依赖、建库）
```

然后访问 **http://127.0.0.1:8000**。

Windows（WSL）用户：双击 `开始学习.bat`（桌面图标同款）；
Linux 桌面用户：双击 `开始学习.desktop`。

其他常用命令：

```bash
./run.sh        # 前台起站（调试用，Ctrl+C 关站）
./check.sh      # 新增内容后自检（格式 + 占位符试算）
./rebuild.sh    # 删库重建（学习数据自动保留）
```

## 自己加内容

只需编辑两个目录，不用碰代码：

- `content/<模块>/<编号-名称>/`：`lesson.md`（课文）+ `quiz.json`（10 题）
- `levels/`：B 型关卡 JSON

课文里的行情数字一律写 `{{calc:...}}` 占位符（语法见 [项目.md](项目.md)），
改完跑 `./check.sh` 自检，绿了再 `./rebuild.sh` 生效。
详细格式说明见 [docs/站长手册.md](docs/站长手册.md)。

## 技术栈

FastAPI + SQLite + 零构建原生 JS 前端（canvas 蜡烛图，无任何前端依赖）。
行情为冻结 CSV（随仓库分发，上证 1996 年起），数据库可由种子文件一键重建、完全离线复现。

